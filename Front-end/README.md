# HarmonySmiles - Dental Clinic

A professional dental clinic website built with **HTML**, **CSS**, **JavaScript**, and **Bootstrap 5**. This website serves as a digital front door for the clinic, providing information about services, team, and appointment booking.

## Features

- **Responsive Design**: Built with Bootstrap 5 to look great on all devices (desktops, tablets, phones).
- **Modern UI**: Clean, modern design with smooth animations and transitions.
- **User-Friendly Navigation**: Intuitive navigation with dropdown menus and sticky header.
- **Interactive Elements**:
    - Appointment booking form with real-time validation.
    - Image carousels for services and testimonials.
    - Contact form.
- **Service Showcase**: Detailed pages for various dental services with high-quality imagery.
- **Team Introduction**: Profiles of the dental team with years of experience and expertise.
- **SEO Optimized**: Semantic HTML structure and proper meta tags.

## Tech Stack

- **HTML5**: For semantic structure.
- **CSS3**: For styling and animations.
- **Bootstrap 5**: For the responsive grid system and UI components.
- **JavaScript (Vanilla)**: For interactive elements and form validation.
- **Font Awesome**: For icons.
- **Google Fonts**: For typography (Poppins, Inter).

## Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/HarmonySmiles.git
    ```
2.  Open `index.html` in your web browser.

## Usage

To run the website locally:

1.  Navigate to the project directory.
2.  Open `index.html` using any modern web browser (Chrome, Firefox, Safari, Edge).
